# Discan

디스크 공간 분석기. 어느 폴더가 용량을 차지하는지, 그리고 그 용량이 **어떤 분야**의
파일인지 함께 보여준다.

## 구성

| 계층 | 기술 |
| --- | --- |
| 셸 | Tauri 2 (Rust) |
| 스캔 커널 | Rust + rayon 병렬 순회 |
| UI | React 19 + TypeScript + Vite |

## 동작

스캔은 `src-tauri/src/scan.rs`의 병렬 재귀 순회로 이루어진다. 설계상 유의점 세 가지.

1. **재해석 지점을 따라가지 않는다.** Windows의 정션·심볼릭 링크·OneDrive 자리표시자를
   따라 들어가면 순환하거나 같은 데이터를 두 번 센다.
2. **분류 힌트는 위에서 아래로 흐른다.** `node_modules` 안의 `.js`는 코드가 아니라
   의존성 캐시다. 디렉터리 이름으로 힌트가 잡히면 하위 전체가 그 분야를 따른다.
3. **트리는 가지치기 후 전달된다.** 전체 노드를 직렬화하면 드라이브 하나에 수십만 개가
   나와 IPC에서 막힌다. 전체의 0.05% 미만은 버리되, 버린 개수는 화면에 남긴다.

읽지 못한 디렉터리(권한 거부 등)는 세어서 결과에 표시한다 — 집계가 실제보다 작다는
신호이므로 조용히 넘기지 않는다.

## 개발

```bash
npm install
npm run tauri dev     # 개발 실행
npm run tauri build   # 배포 번들(MSI/NSIS) 생성
```

### 요구 사항

- Rust (stable, MSVC 툴체인)
- Visual Studio Build Tools + MSVC C++ 워크로드
- WebView2 런타임 (Windows 11 기본 탑재)
- Node.js 20+
